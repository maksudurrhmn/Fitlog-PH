# Fitlog-PH

A modern workout planning web application built with Next.js. Browse workouts, view detailed exercise information, create your daily workout plan, and save your favorite exercises.

## 🔗 Live Demo

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Visit%20Site-CCFF00?style=for-the-badge&logo=vercel&logoColor=black)](https://fitlogph.vercel.app)

## 🚀 Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- React Hot Toast
- REST API

## ✨ Key Features

- 🏋️ **Workout Library** — Browse a collection of workouts with details such as duration, calories, difficulty, rating, and equipment.
- 📋 **Daily Workout Plan** — Add workouts to your plan with a maximum of 5 exercises.
- 🔖 **Save Workouts** — Save your favorite workouts for quick access later.
- 🔍 **Workout Details** — View complete workout information, muscle groups, equipment, sets, reps, and instructions.
- 📊 **Plan Statistics & Sorting** — See total exercises, workout duration, and calories, with sorting by duration, calories, or rating.

## 📱 Responsive Design

Fully responsive interface designed for desktop, tablet, and mobile devices.

## 🎨 Design

Fitlog-PH features a modern dark-themed interface with a lime accent color and clean typography for a focused workout experience.
